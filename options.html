IMDb Custom Links — Options

Define one or more URL templates below. Each becomes a link shown on every IMDb title page. Use these placeholders anywhere in the URL — they'll be filled in automatically from the page you're viewing:
{imdb_id} — e.g. tt0111161   {title} — movie/show title   {year} — release year   {url} — the current IMDb page URL   {stremio_type} — auto-detected "movie" or "series"

Example for opening the title directly in the Stremio app (requires Stremio installed):
stremio:///detail/{stremio_type}/{imdb_id}/{imdb_id}
